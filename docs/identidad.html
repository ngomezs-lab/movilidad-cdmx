Galería visual

Galería del proyecto

Esta sección reúne las piezas visuales, pruebas gráficas, murales, aplicaciones y retratos conceptuales que construyen el universo de Movilidad CDMX. La galería está pensada para que cada pieza se sienta parte de una misma narrativa urbana: contraste alto, atmósfera nocturna, neón sutil y una lectura limpia para explorar cada diseño.

Haz clic en cualquier imagen para verla ampliada. Usa los filtros para moverte entre aplicaciones, carteles, testimonios, muros y piezas especiales.
